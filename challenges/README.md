# Challenges

This folder contains candidate-facing engineering challenges.

## How to Assign

1. Pick a challenge directory.
2. Share the challenge `README.md` with the candidate.
3. Ask for submission through the standard repo workflow:
   - Branch: `solution/<firstname-lastname>`
   - Work location: `solutions/<firstname-lastname>/`
   - PR target: `main`
